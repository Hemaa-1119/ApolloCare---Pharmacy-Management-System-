# ApolloCare – Online Pharmacy Management System

## Overview

Apollo Pharmacy is a small-scale online pharmacy management system developed using J2EE. The application allows users to browse medicines, search products, manage their cart, place orders, and manage their account.

## Features

- User Registration and Login
- Medicine Search and Browsing
- Product Details
- Shopping Cart
- Order Placement
- Order Management
- CRUD Operations
- Session Management
- Client-side JSON Validation
- Server-side Validation
- MySQL Database Integration
- MVC Architecture

## Tech Stack

- Java
- J2EE
- Servlets
- JSP
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- JSON
- Apache Tomcat

## Architecture

MVC Architecture

- Model – Java classes and DAO
- View – JSP
- Controller – Servlets
- Database – MySQL

## Database

MySQL is used for storing:

- User information
- Medicine/product details
- Cart information
- Orders
- Order details

## How to Run

1. Clone the repository.
2. Import the project into Eclipse.
3. Configure Apache Tomcat.
4. Configure the MySQL database.
5. Update database connection details.
6. Start the application using Tomcat.
7. Open the application in the browser.
